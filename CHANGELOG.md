# Xal's Craft Courier - Changelog

## 1.0.4 - August 10, 2026

---

A visual refresh - Craft Courier now shares the same clean, flat button style as the rest of Xal's addons, and you'll see a "what's new" splash automatically after future updates.

### 🆕 Changed
- New flat button style across every panel - Splash, Options, and the mailbox send window - replacing the old beveled/graphic button looks.
- Added a "What's New" splash that shows automatically after an update, summarizing what changed.
- Real Settings page (Options -> Settings) with independent UI Size and Font Size sliders.
- Increased font sizes across the Options panel and mailbox send window to a consistent, more readable minimum.
- Options is now its own floating, draggable window - it no longer opens inside the game's Interface Options / AddOns window.
- Settings now opens as its own separate window next to Options, with live value readouts on the sliders and more spacing throughout.
- Fixed the Options window's content sitting flush against its edges with no buffer, and the header's close button overlapping the Settings button.
- Fixed uneven padding on the profession list buttons and gave the header more room around the close button.
- Fixed the header bar rendering outside the panel's own border, replaced the red close button with the branded style, and made the window larger overall.
- Added a minimap button - left-click opens Options, right-click opens the Send Preview. Toggle it on/off from Options -> Settings.

---

## 1.0.3 - August 8, 2026

---

The v1.0.0 release announcement never actually went out (a release-automation issue, now fixed), so this release rolls up everything since the very first version alongside what's new in 1.0.3, so nothing gets missed.

### 🆕 Everything since the first version
- **Assign a dedicated crafter for every profession** - Alchemy, Blacksmithing, Enchanting, and the rest, each with their own recipient.
- **True one-click mailing at any mailbox** - a themed "Send to Crafters" button appears on the Send Mail frame; hit Send All and every mail sends itself, one after another. Drag the button anywhere you like and right-click to lock it in place.
- **Personal and Guild tabs** - send to your own alts or your guild's crafters, always a deliberate, separate choice - guild crafters are kept fully separate per guild.
- **Profession list in the send window** - every profession is listed, with a green dot marking which ones have something ready to send right now.
- **Smart bag scanning** - reads every bag, including the reagent bag, and matches items to professions automatically.
- **Filter system** - control exactly which expansions and item types (reagents, tools, recipes) get sent to each crafter.
- **Full guild crafter support** - pulls your live guild roster straight into the crafter picker, no manual typing.
- **Quick setup screen** - a guided first-run panel to assign crafters in seconds, with a deeper Options panel for fine-tuning.
- **Plays nicely with other mailing addons** - works correctly alongside TSM and similar addons that customize the mailbox.

### 🔧 New in 1.0.3
- Increased the Send Preview window's title size and added more breathing room between it and the Personal/Guild tabs.
- Added a second button style for the profession list in the send window - a thicker, 3D beveled look. Switch between the two under Options -> Settings, a new dedicated settings page.
